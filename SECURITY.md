# Security Policy

## Sensitive project files

Adobe Premiere Pro `.prproj` files can contain local paths, usernames, project names, clip names, client names, and other production metadata.

Do not attach private `.prproj` files to public issues. Share a sanitized excerpt or synthetic reproducer instead.

## Reporting security or privacy issues

Use GitHub private vulnerability reporting if it is enabled for this repository.

If private vulnerability reporting is not enabled, email the maintainer listed on the GitHub profile. If you cannot use email, open a public issue with a minimal description and do not include sensitive files, paths, names, or unreleased production details. The maintainer can arrange a safer follow-up channel if needed.
