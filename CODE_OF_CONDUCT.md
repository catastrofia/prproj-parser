# Code of Conduct

We want this project to be useful and welcoming.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, but accept feedback when impact differs from intent.
- Keep discussions focused on the project.
- Respect privacy; do not share private project files or personal data without permission.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without consent.
- Repeated disruption after maintainers ask you to stop.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or PRs; or block participants who violate this code. Report problems through GitHub private vulnerability reporting if available, or open a minimal public issue asking for a private maintainer contact without including private details.
